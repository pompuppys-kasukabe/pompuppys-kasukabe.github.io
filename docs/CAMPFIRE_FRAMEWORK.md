## 構成のポイント

1. **スクロール時間を短縮**
   - 読了時間3分以内を目指す
   - 写真で語り、文章は補足

2. **感情の流れを設計**
   - 共感（苦しかった）→ 感動（復活）→ 応援したい（支援）

3. **数字で信頼感**
   - 費用の透明性
   - スケジュールの明確化

4. **行動を促す**
   - 「一緒に戦う」という参加意識
   - 横断幕への名前掲載で"自分ごと化"
